# Фиктивные переменные и отбор регрессоров

## Кратко

- Значимость регрессии в целом (F-критерий) и значимость коэффициентов (t-критерий) — разные нулевые гипотезы; их расхождение — первый признак мультиколлинеарности.
- VIF ниже порога не доказывает отсутствие мультиколлинеарности: в примере все VIF < 10, но индекс обусловленности показывает проблему.
- Два базовых способа отбора переменных — метод исключения и метод включения; к одной модели они приходить не обязаны.
- **Фиктивная (dummy) переменная** — категориальная переменная 0/1. Позволяет строить одну регрессию вместо нескольких по подвыборкам и не терять степени свободы.
- Включение dummy бывает аддитивным (сдвиг свободного члена), мультипликативным (изменение наклона) и смешанным.
- Признак с $N$ градациями кодируется $N-1$ фиктивной переменной. $N$ переменных дают полную мультиколлинеарность.
- Кодировать категории числами 1, 2, 3 нельзя: это вносит порядок, которого в данных нет.

## Разбор примера: цены квартир в Москве

Модель на логарифмах: $\ln(\text{цена})$ от логарифмов площадей и других характеристик.

- **F-статистика**: p-value фактически нулевой → отвергаем $H_0$ о незначимости регрессии **в целом**. Цена зависит от этого набора переменных.
- **t-статистики**: значим только коэффициент при логарифме общей площади. Три из четырёх незначимы.

> [!IMPORTANT]
> Нулевых гипотез несколько, путать нельзя. $H_0$ по F-критерию — «регрессия незначима в целом». $H_0$ по t-критерию — «данный коэффициент равен нулю». Регрессия может быть значима по F, даже если незначимы **все** коэффициенты до одного. Это противоречие — самый первый признак мультиколлинеарности.

VIF обманчивы: максимальный около 7, ни один не превышает 10 — формально мультиколлинеарности «нет». Но индекс обусловленности (CI) велик и перевешивает: мультиколлинеарность есть.

## Способы борьбы с мультиколлинеарностью

### Метод исключения (backward)

Применим, только если модель с полным набором переменных строится.

1. Построить модель со всеми нужными переменными.
2. Найти **самую плохую** — с наибольшим p-value.
3. Удалить и переоценить модель.
4. Повторять, пока остаются незначимые коэффициенты.

В примере с квартирами после двух шагов остаётся зависимость только от общей площади.

### Метод включения (forward)

Нужен, когда полная модель не строится (частый случай).

1. Построить корреляционную матрицу, включив зависимую переменную $Y$.
2. Взять $X$, с которым $Y$ коррелирует сильнее всего — модель первого шага.
3. Перебрать оставшиеся переменные на второе место, оставить дающую наибольший $R^2$.
4. Повторять, пока очередная добавляемая переменная не окажется незначимой при любом наборе.

> [!NOTE]
> Методы исключения и включения совсем не обязательно дают одинаковую модель — ситуация нередкая. Похожие модели сравнивают дисперсионным анализом (`anova` в R).

### Прочие подходы

| Способ | Суть и ограничение |
|---|---|
| Смириться | Принять высокие стандартные ошибки; оценки остаются несмещёнными |
| Увеличить выборку | Больше наблюдений — устойчивее оценки; данные не всегда доступны |
| Убрать часть переменных | Методы исключения и включения выше |
| LASSO-регрессия | Штраф за большие коэффициенты при минимизации RSS зануляет часть из них, отбор происходит сам |
| Гребневая (ridge) регрессия | Тот же штраф, но коэффициенты не зануляются: оценки стабилизируются при плохо обусловленной матрице |
| Медианная (квантильная) регрессия | Оценивает зависимость медианы (или другого квантиля) $Y$ вместо среднего |
| Метод главных компонент | Строит взаимно ортогональные (некоррелирующие) линейные комбинации исходных переменных |

Обычная регрессия отвечает на вопрос «чему равны **несмещённые** оценки с наименьшей дисперсией?». Ridge, LASSO и главные компоненты дают смещённые оценки — это не порча ответа, а смена вопроса: любая смещённая оценка $\beta$ есть несмещённая оценка другого коэффициента $\gamma$.

Метод главных компонент — вероятно, самый сильный, но **пригоден только для прогнозов**: новые переменные перемешивают исходные, и коэффициенты теряют экономический смысл.

При слабой мультиколлинеарности бороться не нужно. Аналогия лектора: температура 37,1 — вроде и болен, и здоров; скорую не вызывают.

### Обратный переход от логарифма к цене

Прогноз строит `predict` (есть в R и Python), но модель оценена для $\ln(\text{цена})$, а нужна цена:

$$\hat{Y} = e^{\widehat{\ln Y}}$$

Работает тождество $e^{\ln x} = x$. Доверительные интервалы для прогноза считаются там же.

## Фиктивные (dummy) переменные

**Фиктивная переменная** — категориальная переменная 0/1, описывающая два противоположных состояния качественного фактора. Синонимы: **бинарная переменная**, **индикатор**, **фактор**. Название «фиктивная» — неудачный перевод *dummy*; ничего фиктивного в ней нет.

Пример: $D = 0$ — потребитель без высшего образования, $D = 1$ — с высшим.

Зачем. Пусть зарплата зависит от стажа, в выборке мужчины и женщины. Две отдельные регрессии по подвыборкам — глупо: 50 наблюдений делятся на две по 25, степени свободы падают вдвое.

> [!WARNING]
> 25 наблюдений — нижний предел, при котором вообще можно строить регрессию. Безопасная граница — от 30. Меньше 25 допустимо, только когда чётко понимаешь, что делаешь.

Правильно — одна регрессия по всей выборке с добавленной dummy.

### ANOVA- и ANCOVA-модели

| Тип модели | Состав переменных | Свойство |
|---|---|---|
| **ANOVA-модель** (дисперсионный анализ) | Только качественные | Кусочно-постоянная функция |
| **ANCOVA-модель** (ковариационный анализ) | И количественные, и качественные | Встречается не реже; это все модели ниже |

Пример ANOVA — зависимость начальной зарплаты только от факта высшего образования:

$$\hat{y} = a + b \cdot D$$

При $D = 0$ зарплата равна $a$, при $D = 1$ — $a + b$. Промежуточных значений нет, отсюда «кусочно-постоянная».

### Аддитивное включение

$$\hat{y} = a + bx + d \cdot sex$$

При $sex = 0$ (базовая категория) остаётся $\hat{y} = a + bx$; при $sex = 1$ — $\hat{y} = (a + d) + bx$.

Наклон одинаков, прямые параллельны, различаются свободным членом на $d$. Данные «зарплата (\$) от трудового стажа (лет)»:

| Группа | Уравнение прямой |
|---|---|
| Женщины ($sex = 0$) | $y = 9{,}2092x + 100{,}31$ |
| Мужчины ($sex = 1$) | $y = 9{,}2394x + 259{,}96$ |

Наклоны различаются на четыре сотых — прямые визуально параллельны. Разница свободных членов и есть $d = 159{,}65$.

Кодировку выбирают так, чтобы категория с бо́льшими значениями получила единицу — тогда $d$ положителен. Обратная кодировка допустима, $d$ станет отрицательным. Категория с нулём — **базовая**, остальные отсчитываются от неё.

### Мультипликативное включение

$$\hat{y} = a + (b + d \cdot sex)x$$

При $sex = 0$: $\hat{y} = a + bx$. При $sex = 1$: $\hat{y} = a + (b + d)x$.

Свободный член общий — прямые выходят почти из одной точки на оси ординат, но под разными углами. Данные «расходы на одежду от уровня дохода»:

| Группа | Уравнение прямой |
|---|---|
| Женщины | $y = 14{,}162x + 58{,}305$ |
| Мужчины | $y = 6{,}273x + 58{,}233$ |

Свободные члены совпадают до долей процента, наклоны различаются вдвое: с каждого дополнительного рубля дохода женщины тратят на одежду заметно больше. Здесь $d < 0$, потому что мужская прямая ниже.

> [!TIP]
> Проверяйте порядок величины коэффициента. Наклон 14 означал бы 14 ₽ расходов с каждого дополнительного рубля дохода — так не бывает. Значит, $X$ и $Y$ в разных единицах (доход в сотнях или расходы в копейках). Тот же сигнал на графике: угол наклона больше 45°, хотя коэффициенту 1 соответствует ровно 45°.

### Смешанная модель

$$\hat{y} = a + b \cdot x + d \cdot sex + f \cdot sex \cdot x$$

Различаются и свободный член, и наклон.

> [!TIP]
> Если непонятно, какая модель нужна, начинать со **смешанной**: незначимую часть потом отбросить. По графику: доверительные интервалы (серая полоса) не пересекаются → различие значимо; линии параллельны → аддитивная модель; под разными углами → мультипликативная.

## Кодирование признаков с несколькими градациями

Пусть товар бывает красным, зелёным и синим. Почему нельзя кодировать 1, 2, 3 (а также RGB- или двоичным кодом):

- Числа упорядочены, а цвета — нет. Вносим в данные **артефакт** упорядоченности, которого в них не было.
- Результат зависит от произвола нумерации: перекодируем красный с 1 на 3 — получим другую регрессию.
- Коэффициент означал бы «изменение цены при переходе от цвета 1 к цвету 2», причём одинаковое на каждом шаге. Бессмыслица.

Правильно: **число новых переменных = число градаций минус одна**. Для трёх цветов достаточно `is_red` и `is_green`; `is_blue` не нужна — если обе нули, цвет синий.

Почему нельзя завести все три:

$$\text{is\_red} + \text{is\_green} + \text{is\_blue} = 1 \quad \text{для любого наблюдения}$$

Переменные точно связаны линейно: по двум восстанавливается третья. Это **полная** мультиколлинеарность — не «плохие коэффициенты», а деление $0/0$, коэффициентов нет.

Тот же аргумент для пола: две категории → одна переменная. Для 10 градаций — 9 переменных.

Вручную задавать не нужно: в R и Python достаточно объявить переменную качественной (фактором) — набор dummy сгенерируется сам. **Качественная переменная** — та, с которой нельзя производить математические действия и нельзя даже установить порядок.

Работа в `ggplot2`. В Python та же грамматика графиков реализована пакетом `plotnine`, код переносится почти без изменений — различия на уровне отдельных эстетик в `aes()`.

```r
boxplot(x)       # точки выше и ниже «усов» — выбросы
```

Что видно:

- Аномальная цена (700 тыс. \$) и площадь (~200 м²) помечаются как выбросы.
- **Но эти точки — не аномалии.** Логарифмирование убирает часть выбросов, но не все.

> [!IMPORTANT]
> Вместо удаления выбросов лучше ввести для них отдельную dummy (1 — аномальная группа, 0 — остальные) и построить одну смешанную модель. Причина содержательная: для квартир до 100 м² и свыше 100 м² у покупателя **разные модели формирования цены**.

### Пример с двумя категориальными переменными

- `floor`: 0 — крайний этаж (первый или последний), 1 — внутренний. Крайние дешевле. На графике $\ln(price)$ от $\ln(totsp)$ прямые под разными углами — зависимость **мультипликативная**.
- `brick`: 0 — панель, 1 — кирпич. Кирпичный дороже. Прямые расходятся почти параллельно — зависимость **аддитивная**.

На нелогарифмированных данных углы наклона выражены сильнее: логарифмирование «придавливает» значения и делает различия менее заметными.

При включении обеих переменных получаются четыре линии. Самая дорогая комбинация — кирпичный дом и внутренний этаж, самая дешёвая — панель и крайний. **Две средние линии накладываются**: удешевление за счёт панели и за счёт крайнего этажа дают одинаковый эффект, различие несущественно.

> [!WARNING]
> Типичная ошибка: свалить все переменные в модель разом, а потом «исключить незначимые». При многих категориальных переменных возникает мультиколлинеарность, и на исключении можно выбросить лишнее. Сначала графики и анализ структуры данных, потом модель.

### Тест Чоу

Точку разделения выборки не обязательно брать «на глаз». **Тест Чоу** (Chow Test, Regression stability Test) проверяет гипотезу о совпадении уравнений регрессии для отдельных групп наблюдений. В него подставляют кандидатов (90, 100, 110, 120 м²) и смотрят, где смена модели подтверждается лучше всего.

Когда нужен:

1. Есть подозрение, что выборка состоит из двух и более разных подвыборок — например, из-за различия качественной переменной.
2. К выборке нужно присоединить дополнительные данные, и требуется выяснить, регрессионно ли однородны обе выборки.

Альтернатива: построить интервальные оценки параметров по каждой подвыборке и посмотреть, пересекаются ли доверительные интервалы. Работает только при достаточном объёме **обеих** подвыборок — при малом объёме хотя бы одной надёжных оценок нет, остаётся только тест Чоу.

## Разведочный анализ данных

### Мозаичная диаграмма

Инструмент для взаимодействий сразу трёх и более категориальных переменных, где обычные графики не помогают. Есть в R и Python.

Как читается:

1. Высоты и ширины прямоугольников пропорциональны числу наблюдений в категориях. Панельных домов вдвое больше кирпичных → полоса вдвое выше.
2. **Площадь** прямоугольника соответствует числу наблюдений с данной комбинацией значений.
3. Цвет — стандартизированный остаток Пирсона, отклонение фактического числа наблюдений от ожидаемого:

| Остаток | Цвет | Смысл |
|---|---|---|
| от $-2$ до $+2$ | серый | отклонение в норме, взаимодействия нет |
| $> +2$ | синий | наблюдений больше ожидаемого, взаимодействие положительное |
| $< -2$ | красный | наблюдений меньше ожидаемого, взаимодействие отрицательное |

Логика цветов англосаксонская, обратная привычной: красное — «опасное», синее — нет. В некоторых пакетах она совпадает с нашей — читайте подписи.

### Boxplot с вырезом (notch)

```r
boxplot(mpg ~ cyl, data = mtcars, notch = TRUE, varwidth = TRUE, col = "red",
        xlab = "Number of Cylinders", ylab = "Miles Per Gallon")
```

- `notch = TRUE` рисует вырез вокруг медианы. Правило: **если вырезы двух ящиков пересекаются, различие медиан незначимо** — визуальный аналог проверки гипотезы.
- `varwidth = TRUE` делает ширину ящика пропорциональной размеру подвыборки.
- Границы ящика — первый и третий квартили, линия внутри — медиана.

Разбиение по двум признакам — через произведение факторов:

```r
mtcars$cyl.f <- factor(mtcars$cyl, levels = c(4, 6, 8))
mtcars$am.f  <- factor(mtcars$am, levels = c(0, 1), labels = c("auto", "standard"))
boxplot(mpg ~ am.f * cyl.f, data = mtcars, varwidth = TRUE, col = c("gold", "darkgreen"))
```

Выводы:

- Расход растёт с числом цилиндров: четырёхцилиндровые экономичнее шести- и восьмицилиндровых, вырезы не пересекаются.
- У четырёхцилиндровых механическая трансмиссия заметно экономичнее автоматической. Выбор зависит от задачи: удобство автомата против экономии топлива.
- У восьмицилиндровых разницы между трансмиссиями нет — медианы совпадают. Видно лишь, что машин с автоматом в выборке гораздо больше.

### Точечная диаграмма

Сырой `dotchart` (пробег по горизонтали, марки по вертикали) не читается — точки без структуры:

```r
dotchart(mtcars$mpg, labels = row.names(mtcars), cex = 0.7)
```

После сортировки, группировки по числу цилиндров и раскраски групп график сразу даёт выводы:

```r
x <- mtcars[order(mtcars$mpg), ]
x$cyl <- factor(x$cyl)
x$color[x$cyl == 4] <- "red"
x$color[x$cyl == 6] <- "blue"
x$color[x$cyl == 8] <- "darkgreen"
dotchart(x$mpg, labels = row.names(x), cex = 0.7, pch = 19,
         groups = x$cyl, gcolor = "black", color = x$color)
```

1. Наибольший пробег на галлоне — у четырёхцилиндровых.
2. Cadillac и Lincoln с аномально малым пробегом — те самые выбросы с боксплота.
3. Диапазоны соседних групп перекрываются: худшие четырёхцилиндровые сравнимы с лучшими шестицилиндровыми, шестицилиндровые — с восьмицилиндровыми.

Смысл разведочного анализа: голая таблица чисел не говорит ничего, а те же данные на графиках дают выводы за минуты. В дипломе такие графики — рабочий инструмент анализа, а не украшение.

- Данные сортируются по dummy (например, `brick`), запоминается номер наблюдения, где нули сменяются единицами, и это число вводится в диалоге теста как точка разделения. Альтернативно указывается имя самой фиктивной переменной.
- Расширенная регрессия теста включает исходные регрессоры плюс переменные вида `splitdum`, `sd_livesp`, `sd_metrdist` — произведения dummy разбиения на каждый регрессор.
- Результат — F-статистика и p-значение для структурных изменений в точке. Большое p-значение (в примере $0{,}4078$) означает структурную однородность подвыборки, то есть единое уравнение для обеих частей.

## Термины

| Термин | Значение |
|---|---|
| Фиктивная (dummy) переменная | Категориальная переменная 0/1; синонимы — бинарная переменная, индикатор, фактор |
| Качественная переменная | Переменная, с которой нельзя производить арифметические действия и нельзя установить порядок |
| Базовая категория | Градация, при которой все dummy данного признака равны нулю |
| ANOVA-модель | Регрессия только на качественных переменных; кусочно-постоянная функция |
| ANCOVA-модель | Регрессия и на количественных, и на качественных переменных |
| Аддитивное включение | Dummy входит слагаемым: меняется свободный член, наклон общий |
| Мультипликативное включение | Dummy умножается на регрессор: меняется наклон, свободный член общий |
| Смешанная модель | Различаются и свободный член, и наклон |
| Полная мультиколлинеарность | Точная линейная связь регрессоров; коэффициенты не существуют |
| Метод исключения | Последовательное удаление переменной с наибольшим p-value |
| Метод включения | Последовательное добавление переменной с наибольшим приростом $R^2$ |
| Метод главных компонент | Замена регрессоров ортогональными линейными комбинациями; пригоден только для прогноза |
| Тест Чоу | Проверка гипотезы о совпадении уравнений регрессии для подвыборок |
| Мозаичная диаграмма | График частот категориальных комбинаций с цветовой индикацией остатков Пирсона |
| Notch на boxplot | Вырез вокруг медианы; пересечение вырезов = различие медиан незначимо |
| `plotnine` | Python-реализация грамматики графиков `ggplot2` |
