# Фиктивные переменные и отбор регрессоров

## Кратко

- Значимость регрессии в целом (F-критерий) и значимость отдельных коэффициентов (t-критерий) — разные нулевые гипотезы. Их расхождение и есть первый признак мультиколлинеарности.
- VIF ниже порога не доказывает отсутствие мультиколлинеарности: в разобранном примере все VIF < 10, но индекс обусловленности показывает проблему.
- Два базовых способа отбора переменных — метод исключения и метод включения. Они не обязаны приводить к одной и той же модели.
- **Фиктивная (dummy) переменная** — обычная категориальная переменная со значениями 0/1. Она позволяет строить одну регрессию вместо нескольких по подвыборкам и не терять степени свободы.
- Включение dummy бывает аддитивным (сдвиг свободного члена), мультипликативным (изменение наклона) и смешанным.
- Признак с $N$ градациями кодируется $N-1$ фиктивной переменной. $N$ переменных дают полную мультиколлинеарность.
- Кодировать категории числами 1, 2, 3 нельзя: это вносит порядок, которого в данных нет.

## Разбор примера: цены квартир в Москве

Модель на логарифмах: $\ln(\text{цена})$ от логарифмов площадей и других характеристик.

Что говорят цифры:

- **F-статистика**: p-value фактически нулевой → отвергаем $H_0$ о незначимости регрессии **в целом**. Цена действительно зависит от этого набора переменных.
- **t-статистики**: значим только коэффициент при логарифме общей площади. Три коэффициента из четырёх незначимы.

> [!IMPORTANT]
> Здесь несколько разных нулевых гипотез, и путать их нельзя. $H_0$ по F-критерию — «регрессия незначима в целом». $H_0$ по t-критерию — «данный коэффициент равен нулю». Регрессия может быть значима по F, даже если незначимы **все** коэффициенты до одного. Именно это противоречие — самый первый признак мультиколлинеарности.

При этом VIF ведут себя обманчиво: максимальный около 7, ни один не превышает 10 — формально мультиколлинеарности «нет». Но индекс обусловленности (CI) велик, и это перевешивает: мультиколлинеарность есть.

## Способы борьбы с мультиколлинеарностью

### Метод исключения (backward)

Применим, только если модель с полным набором переменных вообще строится.

1. Построить модель со всеми переменными, которые считаем нужными.
2. Найти **самую плохую** переменную — с наибольшим p-value.
3. Удалить её и переоценить модель заново.
4. Повторять, пока остаются незначимые коэффициенты.

В примере с квартирами после двух шагов остаётся зависимость только от общей площади.

### Метод включения (forward)

Нужен, когда полная модель не строится (а это частый случай).

1. Построить корреляционную матрицу, включив в неё зависимую переменную $Y$.
2. Взять тот $X$, с которым $Y$ коррелирует сильнее всего — это модель первого шага.
3. Перебрать все оставшиеся переменные как кандидата на второе место, оставить ту, что даёт наибольший $R^2$.
4. Повторять, пока очередная добавляемая переменная не окажется незначимой при любом наборе.

> [!NOTE]
> Методы исключения и включения совершенно не обязательно приводят к одинаковой модели — это нередкая ситуация. Сравнивать похожие модели между собой можно дисперсионным анализом (`anova` в R).

### Прочие подходы

| Способ | Суть и ограничение |
|---|---|
| Смириться | Принять высокие стандартные ошибки как есть; оценки остаются несмещёнными |
| Увеличить выборку | Больше наблюдений — устойчивее оценки; данные не всегда доступны |
| Убрать часть переменных | Методы исключения и включения выше |
| LASSO-регрессия | Штраф за большие коэффициенты при минимизации RSS зануляет часть из них, отбор происходит сам |
| Гребневая (ridge) регрессия | Тот же штраф, но коэффициенты не зануляются: оценки стабилизируются при плохо обусловленной матрице |
| Медианная (квантильная) регрессия | Оценивает зависимость медианы (или другого квантиля) $Y$ от регрессоров вместо среднего |
| Метод главных компонент | Строит взаимно ортогональные (некоррелирующие) линейные комбинации исходных переменных |

Обычная регрессия отвечает на вопрос «чему равны **несмещённые** оценки с наименьшей дисперсией?». Ridge, LASSO и главные компоненты дают смещённые оценки — и это не порча ответа, а смена вопроса: любая смещённая оценка коэффициента $\beta$ есть несмещённая оценка какого-то другого коэффициента $\gamma$.

Метод главных компонент — вероятно, самый сильный, но **пригоден только для прогнозов**: новые переменные перемешивают исходные, и коэффициенты при них теряют экономический смысл.

Если мультиколлинеарность выражена слабо, бороться с ней не нужно вовсе. Аналогия лектора: температура 37,1 — вроде и болен, и здоров; скорую не вызывают.

### Обратный переход от логарифма к цене

Прогноз строится функцией `predict` (есть и в R, и в Python), но модель оценена для $\ln(\text{цена})$, а нужна сама цена:

$$\hat{Y} = e^{\widehat{\ln Y}}$$

Работает школьное тождество $e^{\ln x} = x$. Доверительные интервалы для прогноза считаются там же.

## Фиктивные (dummy) переменные

**Фиктивная переменная** — категориальная переменная, принимающая значения 0 или 1 и описывающая два противоположных состояния качественного фактора. Другие названия: **бинарная переменная**, **индикатор**, **фактор**. Название «фиктивная» — неудачный перевод английского *dummy*; ничего фиктивного в ней нет.

Простейший пример: $D = 0$, если потребитель не имеет высшего образования, и $D = 1$, если имеет.

Зачем она нужна. Пусть зарплата зависит от стажа, а в выборке есть мужчины и женщины. Можно построить две отдельные регрессии по подвыборкам — но это глупо: 50 наблюдений делятся на две по 25, и число степеней свободы падает вдвое.

> [!WARNING]
> 25 наблюдений — нижний предел, при котором вообще можно строить регрессию. Безопасная граница — от 30. Меньше 25 допустимо только тогда, когда чётко понимаешь, что делаешь.

Правильное решение — одна регрессия по всей выборке с добавленной dummy-переменной.

### ANOVA- и ANCOVA-модели

| Тип модели | Состав переменных | Свойство |
|---|---|---|
| **ANOVA-модель** (модель дисперсионного анализа) | Только качественные | Кусочно-постоянная функция |
| **ANCOVA-модель** (модель ковариационного анализа) | И количественные, и качественные | Встречается не реже; это все модели ниже |

Пример ANOVA-модели — зависимость начальной зарплаты только от факта высшего образования:

$$\hat{y} = a + b \cdot D$$

При $D = 0$ зарплата равна $a$, при $D = 1$ — равна $a + b$. Никаких промежуточных значений функция не принимает, отсюда и «кусочно-постоянная».

### Аддитивное включение

$$\hat{y} = a + bx + d \cdot sex$$

При $sex = 0$ (базовая категория) остаётся $\hat{y} = a + bx$; при $sex = 1$ получается $\hat{y} = (a + d) + bx$.

Наклон одинаков, прямые параллельны, различаются только свободным членом на величину $d$. На данных «зарплата (\$) от трудового стажа (лет)»:

| Группа | Уравнение прямой |
|---|---|
| Женщины ($sex = 0$) | $y = 9{,}2092x + 100{,}31$ |
| Мужчины ($sex = 1$) | $y = 9{,}2394x + 259{,}96$ |

Коэффициенты наклона различаются на четыре сотых — визуально прямые параллельны. Разница свободных членов и есть $d = 159{,}65$.

Кодировка выбирается так, чтобы категория с бо́льшими значениями получила единицу — тогда $d$ положителен. Обратная кодировка допустима, просто $d$ станет отрицательным. Категория с нулём — **базовая**, остальные отсчитываются от неё.

### Мультипликативное включение

$$\hat{y} = a + (b + d \cdot sex)x$$

При $sex = 0$: $\hat{y} = a + bx$. При $sex = 1$: $\hat{y} = a + (b + d)x$.

Свободный член общий — прямые выходят практически из одной точки на оси ординат, но идут под разными углами. На данных «расходы на одежду от уровня дохода»:

| Группа | Уравнение прямой |
|---|---|
| Женщины | $y = 14{,}162x + 58{,}305$ |
| Мужчины | $y = 6{,}273x + 58{,}233$ |

Свободные члены совпадают с точностью до долей процента, а наклоны различаются вдвое: с каждого дополнительного рубля дохода женщины тратят на одежду заметно больше. Здесь $d < 0$, потому что мужская прямая проходит ниже.

> [!TIP]
> Проверяйте порядок величины коэффициента. Наклон 14 означал бы 14 ₽ дополнительных расходов с каждого дополнительного рубля дохода — так не бывает. Значит, $X$ и $Y$ измерены в разных единицах (доход в сотнях либо расходы в копейках). Тот же сигнал виден на графике: угол наклона больше 45°, хотя коэффициенту 1 соответствует ровно 45°.

### Смешанная модель

$$\hat{y} = a + b \cdot x + d \cdot sex + f \cdot sex \cdot x$$

Различаются и свободный член, и наклон.

> [!TIP]
> Если непонятно, какая модель нужна, начинать надо со **смешанной**: незначимую часть потом просто отбросить. По графику ориентируются так: доверительные интервалы (серая полоса) не пересекаются → различие значимо; линии параллельны → аддитивная модель; идут под разными углами → мультипликативная.

## Кодирование признаков с несколькими градациями

Пусть товар бывает красным, зелёным и синим. Почему нельзя закодировать 1, 2, 3 (а также RGB-кодом или двоичным кодом):

- Числа упорядочены, а цвета — нет. Мы вносим в данные **артефакт** упорядоченности, которого в них исходно не было.
- Результат начинает зависеть от произвола нумерации: перекодируем красный с 1 на 3 — получим другую регрессию.
- Коэффициент при такой переменной означал бы «изменение цены при переходе от цвета 1 к цвету 2», причём одинаковое на каждом шаге. Это бессмыслица.

Правильный способ: **количество новых переменных = количество градаций минус одна**. Для трёх цветов достаточно `is_red` и `is_green`; `is_blue` не нужна — если обе равны нулю, цвет синий.

Почему нельзя завести все три:

$$\text{is\_red} + \text{is\_green} + \text{is\_blue} = 1 \quad \text{для любого наблюдения}$$

Переменные точно связаны линейным соотношением: по двум всегда восстанавливается третья. Это **полная** мультиколлинеарность — не «плохие коэффициенты», а деление $0/0$, коэффициентов нет вообще.

Тот же аргумент для пола: две категории → одна переменная. Для 10 градаций — 9 переменных.

Вручную это задавать не нужно: и в R, и в Python достаточно объявить переменную качественной (фактором) — нужный набор dummy сгенерируется сам. **Качественная переменная** — та, с которой нельзя производить математические действия и нельзя даже установить порядок.

Работа идёт в `ggplot2`. В Python та же грамматика графиков реализована пакетом `plotnine`, код переносится почти без изменений — различия остаются на уровне отдельных эстетик в `aes()`.

```r
x <- f$totsp     # общая площадь; $ достаёт столбец из фрейма
y <- f$price
boxplot(x)       # точки выше и ниже «усов» — выбросы
```

Что видно на графиках:

- Аномально большая цена (700 тыс. \$) и аномально большая площадь (~200 м²) помечаются как выбросы.
- **Но эти точки — не аномалии.** Логарифмирование часть выбросов убирает, но не все.

> [!IMPORTANT]
> Вместо удаления выбросов лучше ввести для них отдельную фиктивную переменную (1 — аномальная группа, 0 — остальные) и построить одну модель смешанного типа. Причина содержательная: для квартир до 100 м² и свыше 100 м² у покупателя работают **разные модели формирования цены**.

### Пример с двумя категориальными переменными

- `floor`: 0 — крайний этаж (первый или последний), 1 — внутренний. Крайние этажи дешевле. На графике $\ln(price)$ от $\ln(totsp)$ прямые идут под разными углами — зависимость **мультипликативная**.
- `brick`: 0 — панельный дом, 1 — кирпичный. Кирпичный дороже. Прямые расходятся почти параллельно — зависимость **аддитивная**.

На нелогарифмированных данных углы наклона выражены сильнее: логарифмирование «придавливает» значения и делает различия менее заметными.

При одновременном включении обеих переменных получаются четыре линии. Самая дорогая комбинация — кирпичный дом и внутренний этаж, самая дешёвая — панельный и крайний. **Две средние линии накладываются друг на друга**: удешевление за счёт панели и за счёт крайнего этажа дают одинаковый эффект, различие между этими комбинациями несущественно.

> [!WARNING]
> Типичная ошибка: свалить все переменные в модель разом, а потом «просто исключить незначимые». При большом числе категориальных переменных возникает мультиколлинеарность, и на исключении появляются нехорошие эффекты — можно выбросить лишнее. Сначала графики и анализ структуры данных, потом модель.

### Тест Чоу

Точку разделения выборки не обязательно брать «на глаз». **Тест Чоу** (Chow Test, Regression stability Test) проверяет гипотезу о совпадении уравнений регрессии для отдельных групп наблюдений. В него подставляют кандидатов (90, 100, 110, 120 м²) и смотрят, где предположение о смене модели подтверждается лучше всего.

Две ситуации, когда он нужен:

1. Есть подозрение, что исходная выборка состоит из двух или более разных подвыборок — например, из-за различия качественной переменной.
2. К имеющейся выборке нужно присоединить дополнительные данные, и требуется выяснить, можно ли считать обе выборки регрессионно однородными.

Альтернатива тесту: построить интервальные оценки параметров регрессии по каждой подвыборке и посмотреть, пересекаются ли доверительные интервалы. Способ работает только при достаточном объёме **обеих** подвыборок — при малом объёме хотя бы одной надёжных оценок не построить, и остаётся только тест Чоу.

## Разведочный анализ данных

### Мозаичная диаграмма

Инструмент для взаимодействий сразу трёх и более категориальных переменных, где обычные графики не помогают. Есть и в R, и в Python.

Как читается:

1. Высоты и ширины прямоугольников пропорциональны числу наблюдений в категориях. Панельных домов вдвое больше кирпичных → соответствующая полоса вдвое выше.
2. **Площадь** каждого прямоугольника соответствует количеству наблюдений с данной комбинацией значений.
3. Цвет — стандартизированный остаток Пирсона, то есть отклонение фактического числа наблюдений от ожидаемого:

| Остаток | Цвет | Смысл |
|---|---|---|
| от $-2$ до $+2$ | серый | отклонение в пределах нормы, взаимодействия нет |
| $> +2$ | синий | наблюдений больше ожидаемого, взаимодействие положительное |
| $< -2$ | красный | наблюдений меньше ожидаемого, взаимодействие отрицательное |

Логика цветов англосаксонская, обратная привычной: красное — «опасное», синее — нет. В некоторых пакетах она совпадает с нашей, так что подписи надо читать.

```r

```

- `notch = TRUE` рисует вырез вокруг медианы. Правило: **если вырезы двух ящиков пересекаются, различие медиан незначимо**. Это визуальный аналог проверки гипотезы.
- `varwidth = TRUE` делает ширину ящика пропорциональной размеру подвыборки.
- Границы ящика — первый и третий квартили, линия внутри — медиана.

Разбиение сразу по двум признакам делается через произведение факторов:

```r
mtcars$cyl.f <- factor(mtcars$cyl, levels = c(4, 6, 8))
mtcars$am.f  <- factor(mtcars$am, levels = c(0, 1), labels = c("auto", "standard"))
boxplot(mpg ~ am.f * cyl.f, data = mtcars, varwidth = TRUE, col = c("gold", "darkgreen"))
```

Выводы по графикам:

- Расход топлива растёт с числом цилиндров: четырёхцилиндровые машины экономичнее шести- и восьмицилиндровых, вырезы не пересекаются.
- У четырёхцилиндровых механическая трансмиссия заметно экономичнее автоматической. Выбор зависит от задачи: удобство автомата против экономии топлива.
- У восьмицилиндровых разницы между трансмиссиями нет — медианы совпадают. Видно только, что машин с автоматом в выборке гораздо больше.

### Точечная диаграмма

Сырой `dotchart` (пробег по горизонтали, марки по вертикали) не читается — точки разбросаны без структуры:

```r
dotchart(mtcars$mpg, labels = row.names(mtcars), cex = 0.7)
```

Тот же график после сортировки, группировки по числу цилиндров и раскраски групп сразу даёт выводы:

```r
x <- mtcars[order(mtcars$mpg), ]
x$cyl <- factor(x$cyl)
x$color[x$cyl == 4] <- "red"
x$color[x$cyl == 6] <- "blue"
x$color[x$cyl == 8] <- "darkgreen"
dotchart(x$mpg, labels = row.names(x), cex = 0.7, pch = 19,
         groups = x$cyl, gcolor = "black", color = x$color)
```

1. Наибольший пробег на галлоне — у четырёхцилиндровых машин.
2. Cadillac и Lincoln с аномально малым пробегом — те самые выбросы, которые были видны на боксплоте.
3. Диапазоны соседних групп перекрываются: худшие четырёхцилиндровые сравнимы с лучшими шестицилиндровыми, шестицилиндровые — с восьмицилиндровыми.

Смысл разведочного анализа: голая таблица чисел не говорит ничего, а те же данные на графиках дают выводы за минуты. При написании диплома такие графики — рабочий инструмент анализа, а не украшение.

## Термины

| Термин | Значение |
|---|---|
| Фиктивная (dummy) переменная | Категориальная переменная со значениями 0 и 1; синонимы — бинарная переменная, индикатор, фактор |
| Качественная переменная | Переменная, с которой нельзя производить арифметические действия и нельзя установить порядок |
| Базовая категория | Градация, при которой все dummy данного признака равны нулю |
| ANOVA-модель | Регрессия только на качественных переменных; кусочно-постоянная функция |
| ANCOVA-модель | Регрессия и на количественных, и на качественных переменных |
| Аддитивное включение | Dummy входит слагаемым: меняется свободный член, наклон общий |
| Мультипликативное включение | Dummy умножается на регрессор: меняется наклон, свободный член общий |
| Смешанная модель | Различаются и свободный член, и наклон |
| Полная мультиколлинеарность | Точная линейная связь регрессоров; коэффициенты не существуют |
| Метод исключения | Последовательное удаление переменной с наибольшим p-value |
| Метод включения | Последовательное добавление переменной, дающей наибольший прирост $R^2$ |
| Метод главных компонент | Замена регрессоров ортогональными линейными комбинациями; пригоден только для прогноза |
| Тест Чоу | Проверка гипотезы о совпадении уравнений регрессии для подвыборок |
| Мозаичная диаграмма | График частот категориальных комбинаций с цветовой индикацией остатков Пирсона |
| Notch на boxplot | Вырез вокруг медианы; пересечение вырезов = различие медиан незначимо |
| `plotnine` | Python-реализация грамматики графиков `ggplot2` |
